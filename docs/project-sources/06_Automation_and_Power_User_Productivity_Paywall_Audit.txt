Automation & Power-User 
Productivity
Macros, phone macro deck service and command palette
Purpose
A product-requirements audit of features that current public competitors restrict to paid editions, subscriptions, DLC, 
or post-trial licences. The aim is to identify features DK’s Desktop can make available locally and free, while avoiding 
needless duplication of already excellent free/open-source tools.
Scope note: “Complete” here means all premium-gated features explicitly surfaced by the official pricing/comparison/help pages 
reviewed for the named competitors. It is not a claim that every software product in the market or every historical feature flag has 
been enumerated.
Research cut: 16 September 2026. Prices are snapshots and should be rechecked before implementation or publication.

What this means for DK’s Desktop
The best DK requirement is not “copy every premium product.” It is to expose the useful local capability without 
arbitrary quotas, cloud accounts or entitlement checks, while retaining conservative safety boundaries for hardware, 
drivers and automation.
• Prefer one shared engine per technical domain (sensor service, input service, LAN pairing, macro engine) so 
multiple modules do not duplicate privileged background services.
• If an excellent free/open-source product already dominates the category, differentiate through integration, simpler 
UX and verifiable local-only behaviour rather than claiming the feature itself is novel.
• For all risky actions—drivers, fan control, process rules, disk operations—show exactly what will change and 
provide an explicit revert path.
