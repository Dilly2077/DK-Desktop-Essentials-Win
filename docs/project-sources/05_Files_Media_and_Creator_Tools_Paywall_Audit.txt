05 Files Media and Creator Tools Paywall Audit

DK'S DESKTOP ESSENTIALS  /  COMPETITIVE PAYWALL AUDIT
	05
Files, Media & Creator Tools
PDF, image, video/audio, subtitles, screenshots and OCR



Purpose
A product-requirements audit of features that current public competitors restrict to paid editions, subscriptions, DLC, or post-trial licences. The aim is to identify features DK’s Desktop can make available locally and free, while avoiding needless duplication of already excellent free/open-source tools.
Scope note: “Complete” here means all premium-gated features explicitly surfaced by the official pricing/comparison/help pages reviewed for the named competitors. It is not a claim that every software product in the market or every historical feature flag has been enumerated.
Research cut: 16 September 2026. Prices are snapshots and should be rechecked before implementation or publication.


How to read this audit
	Label
	Meaning

	PAYWALLED
	Feature exists in a paid tier, DLC, licence, or only after purchasing the product.

	LIMITED FREE
	The free edition exposes the feature with a cap, time limit or restricted mode.

	FREE BASELINE
	A strong free/open-source competitor already offers this capability; DK needs integration/UX/privacy differentiation.

	DK TARGET
	Feature is a plausible requirement for DK’s free/local implementation; not a promise that implementation is trivial.

	CAUTION
	Feature may require privileged drivers, third-party codecs, vendor SDKs, licensed databases, or other constraints.

PDF-XChange Editor / Editor Plus
	Gate
	Price/model
	Source

	>70% free; licensed functions watermark output; Plus adds advanced features
	Perpetual licence model with maintenance options
	PDF-XChange limitations/comparison


Premium / gated feature inventory
• Licensed functions can be tried in the free build but apply evaluation watermarks to output.
• Licensed feature set includes advanced base-content editing, page/document manipulation, security/encryption, redaction/sanitization, document conversion/export and various automation/batch features shown in the official comparison chart.
• Editor Plus adds Enhanced OCR.
• Editor Plus adds creation/editing of fillable forms and form-recognition workflows.
• Editor Plus adds dynamic stamps and document-comparison features in current product materials.
Free baseline / competitive reality
• Several free tools cover merge/split/rotate well; the real user pain is that advanced editing/OCR/redaction/forms/conversion are often the paid boundary.
Recommended DK free/local target
□ Merge, split, reorder, rotate, extract, insert and delete pages.
□ Compress/optimize images/fonts/metadata with preview.
□ Watermark, headers/footers, page numbers and Bates-style numbering.
□ Fill forms and place signatures locally.
□ Password encryption/decryption where user has authority; permissions display.
□ Redaction that actually removes underlying content.
□ Basic text/image content editing where feasible.
□ OCR to searchable PDF; deskew/rotate/cleanup pipeline.
□ PDF↔image and Office-compatible conversion where open libraries permit.
□ Metadata inspection/removal and sanitize pass.
□ No watermark, page cap or upload requirement.
Implementation cautions
! Office-format conversion fidelity and general PDF text editing are much harder than merge/split. Treat them as later milestones.

FastStone Image Viewer / Photo Resizer commercial licence
	Gate
	Price/model
	Source

	Free personal/education; paid commercial use
	Image Viewer $34.95 one-time commercial licence; Photo Resizer $19.95
	FastStone licensing


Premium / gated feature inventory
• Feature set is not technically paywalled for personal users; commercial use requires a licence. The free personal feature set already includes powerful batch conversion/rename, resize, crop, metadata, comparisons, annotation and many formats.
Free baseline / competitive reality
• FastStone, XnConvert, ImageMagick and other free tools make “batch image conversion” itself a weak differentiator.
• DK can still win through a simpler shared local pipeline, consistent UI, privacy status and integration with Screenshot/PDF/OCR.
Recommended DK free/local target
□ Batch resize with fit/fill/stretch/crop modes.
□ JPG/PNG/WebP/AVIF/HEIC conversion where codecs permit.
□ Quality/size target and live estimate.
□ Rotate/flip/crop; basic brightness/contrast/saturation/sharpness.
□ Metadata view plus remove-all/EXIF/GPS/camera-info choices.
□ Watermark text/image with positioning/opacity.
□ Batch rename and social/preset dimensions.
□ Before/after preview and queue with no item limit.
□ Local processing and readable export log.
Implementation cautions
! HEIC/AVIF codec licensing/availability varies by platform/library. Keep codec modules replaceable.

	Gate
	Price/model
	Source

	Paid product / trial
	$54.95/year shown in current comparison
	Movavi “help me choose”


Premium / gated feature inventory
• Unlimited local media conversion/compression versus online free limits.
• AI video upscaling up to 8×.
• No file/size limit.
• Crop/rotate, filters and enhancement before conversion.
• Bulk conversion.
• Find/add subtitles to videos.
Free baseline / competitive reality
• FFmpeg and HandBrake already provide an extremely capable free/local engine; Subtitle Edit provides a strong free subtitle editor. DK should primarily provide workflow/UI and suite integration.
• Cloud AI transcription/translation has recurring compute cost unless DK uses a local model; keep local inference optional and hardware-aware.
Recommended DK free/local target
□ Video/audio format conversion via local engine.
□ Batch queue, presets and hardware-encode selection.
□ Compression by target size/quality.
□ Audio extraction and channel/sample-rate controls.
□ Trim/crop/rotate without forcing a full editor.
□ Subtitle SRT/VTT edit, timing shift, merge/split and burn-in.
□ Local speech-to-text as optional downloadable model; clearly show model size/compute.
□ Media metadata inspection/removal.
□ No length/file-count watermark limits.
Implementation cautions
! Respect codec/patent/licence obligations; avoid bundling codecs without checking distribution terms.

Recommended DK free/local target

□ Copy/save/export to standard formats; no mandatory cloud share.
□ Optional handoff to DK Image/PDF/OCR modules.
Implementation cautions
! Automated redaction is a safety feature only if the user can verify the result; never claim it guarantees removal of all sensitive data.

What this means for DK’s Desktop
The best DK requirement is not “copy every premium product.” It is to expose the useful local capability without arbitrary quotas, cloud accounts or entitlement checks, while retaining conservative safety boundaries for hardware, drivers and automation.
• Prefer one shared engine per technical domain (sensor service, input service, LAN pairing, macro engine) so multiple modules do not duplicate privileged background services.
• If an excellent free/open-source product already dominates the category, differentiate through integration, simpler UX and verifiable local-only behaviour rather than claiming the feature itself is novel.
• For all risky actions—drivers, fan control, process rules, disk operations—show exactly what will change and provide an explicit revert path.
